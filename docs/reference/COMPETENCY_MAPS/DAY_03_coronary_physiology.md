## L5 objectives (viva summits — write these FIRST, sourced)
1. **Use ISCHEMIA / ISCHEMIA-EXTEND honestly for the specific patient** — in stable disease with
   moderate-to-severe ischemia an initial invasive strategy did **not** reduce all-cause mortality vs
   OMT over a median 3.2 y (EXTEND: lower CV but higher non-CV death, net no all-cause difference),
   trading more periprocedural MI for fewer spontaneous MIs and better angina QoL — *and* the
   criticisms (enrollment cut 8000→5179, low event rates, modest follow-up, left main and the sickest
   excluded) — while this coexists with the surgical survival indications ISCHEMIA did not overturn
   (left main, multivessel + low EF, diabetes + multivessel).
   → hinges on trials [ISCHEMIA/ISCHEMIA-EXTEND, source [ISC]] and numbers [FFR ≤ 0.80 / iFR ≤ 0.89].
2. **The single fastest intervention for the ischemic, tachycardic, anemic, hypotensive patient** —
   rate control + a perfusion-pressure / oxygen-carrying fix over reflexive nitrate-driven afterload
   reduction that drops the diastolic perfusion gradient — defended mechanistically.
